# iPhone Launch Sprint

Dry-run kit for apple.com/vn. It never clicks **Đặt hàng**. `dry_run: true` is required.

**TEST:** iPhone 17 Pro Max · 256GB · Cam Vũ Trụ  
**LAUNCH:** iPhone 18 Pro Max (`mode: launch` in `config.yaml`)

On GitHub, stay on branch **`cursor/dynamic-sku-select`**. Do not click **Compare & pull request**.

`config.yaml` is not on GitHub. Copy `config.example.yaml` on each computer and type the CVV there.

---

## Which computer are you on?

Pick **one**. Mac commands do not work on Windows. Windows commands do not work on a Mac.

- **Windows 11 (including RDP):** open **[checklist.md](checklist.md)** and go to **New Windows 11**. Start at A (install Chrome).
- **Mac:** open **[checklist.md](checklist.md)** and go to **New Mac**. Start at A.

The script you run is **`assist.py`**. The two commands after setup are `--warm-only` then `--now`.
